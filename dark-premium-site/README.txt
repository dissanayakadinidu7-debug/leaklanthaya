DARK PREMIUM WEBSITE STARTER

1. Extract this ZIP file.
2. Open the extracted "dark-premium-site" folder in Visual Studio Code.
3. Open index.html in a browser, or use the VS Code Live Server extension.
4. Replace "YOUR BRAND" and the example contact email in index.html.
5. Edit colors and layout in styles.css.
6. Edit the age notice and navigation behavior in script.js.

IMPORTANT LIMITATIONS AND LAUNCH CHECKLIST
- This is a static front-end starter. The age confirmation is only a browser-side demo and is NOT legally robust age verification.
- A static HTML page cannot securely restrict VIP content, manage memberships, accept subscriptions, or protect private media. Those features require a secure backend, authentication, server-side authorization, and a compliant payment provider.
- Before purchasing a domain or hosting, confirm in writing that the provider permits the intended lawful adult-oriented content. Check payment-provider rules too.
- Publish only lawful content featuring adults (18+), with informed consent and documented rights/licences. Do not upload hidden-camera, non-consensual, or copyrighted material without permission.
- Add legally appropriate age assurance, privacy, terms, content reporting/takedown, and jurisdiction-specific compliance before launch.
- Replace example contact details and have legal/privacy documents reviewed for your jurisdiction.
